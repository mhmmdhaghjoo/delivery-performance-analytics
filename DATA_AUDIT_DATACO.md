# Data audit — DataCo Smart Supply Chain (V5) — 2026-11-19

File audited: `data/DataCoSupplyChainDataset.csv` (95,910,149 bytes, Latin-1, 180,519 rows × 53 columns, 65,752 orders, order dates 2015-01-01 to 2018-01-31). Scripts: profile + signal checks run read-only on a copy.

## Clean structure (good)
- No duplicate rows or order-item IDs. All shipping fields are constant within an order, so order-level aggregation is safe.
- `Delivery Status` and `Late_delivery_risk` agree exactly with real − scheduled days (cancelled orders excepted).
- Personal fields: email and password are fully masked ("XXXXXXXXX"); names and street are present. `Product Description` is 100 % empty.

## Signs that the data is generated by simple rules (OBSERVATION)
1. **Scheduled days are fixed per shipping mode:** Same Day 0, First Class 1, Second Class 2, Standard Class 4.
2. **Real days follow a fixed rule:** First Class is always 2 days, so it is late on 100 % of orders, always by exactly one day. Same Day is 0 or 1 at ~50/50. Second and Standard Class are spread almost perfectly evenly over 2, 3, 4, 5 and 6 days.
3. **Lateness depends on nothing except shipping mode.** On 62,897 shipped orders (late rate 57.3 %), chi-square tests found no association of lateness with market (p = 0.53), customer segment (p = 0.59), payment type (p = 0.70), product category (p = 0.35) or order status (p = 0.66), overall or within shipping modes. Region gives one within-mode p = 0.011 among ~30 tests, which is consistent with chance. The quarterly late rate stays between 56.5 % and 58.7 % for three years.
4. **Lateness has no measurable consequence:** cancellation share is 4.1–4.7 % in every mode and market; mean profit ratio is 12.3 % on-time vs 12.0 % late.
5. **Volume is flat** at ~5,200 orders per month, then drops to ~2,100 per month from October 2017 onwards.

## Consequence for the approved brief
- Q1 and Q3 (promise kept? realistic promise?) are answerable, but trivially: the answer is fixed by the generator (e.g. First Class 0 % on time).
- Q2, Q4 and Q5 (lanes, cost of lateness, lane priority) return null results by construction. A dashboard ranking markets or regions would display noise.
- Many public DataCo projects report "late-delivery prediction" accuracies close to 100 %. Given finding 2, this is the shipping mode, with leakage from `Days for shipping (real)`. That is a useful portfolio lesson, but not a supply-chain decision.
